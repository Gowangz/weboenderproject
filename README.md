## Bahasa Indonesia

weboenderproject adalah website statis sederhana yang dibuat sebagai tugas proyek OSPEK Jurusan Teknik Informatika Komunitas Weboender di UIN Maulana Malik Ibrahim Malang tahun 2023.

*   **Pembuat**: Ilham Saputra
*   **Pendidikan**: Mahasiswa Teknik Informatika di UIN Maulana Malik Ibrahim Malang (Tahun 2023)
*   **Instagram**: [@ilham.sptraa](https://www.instagram.com/ilham.sptraa/)

### Teknologi yang Digunakan
*   **HTML5**: Struktur halaman web.
*   **CSS3**: Desain dan tata letak yang menarik.
*   **JavaScript**: Menambahkan interaktivitas sederhana.
